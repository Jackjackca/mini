Based on the original [mini](https://github.com/Orz-3/mini) icon project by Orz-3.

# Egern Icon Sets

In Egern, open the icon set page (图标集), add a remote set, and paste one or more of the following URLs:

- Alpha Airports: `https://raw.githubusercontent.com/Jackjackca/mini/master/alpha-airports.json`
- Alpha Subscription Types: `https://raw.githubusercontent.com/Jackjackca/mini/master/alpha-types.json`
- Alpha General Icons: `https://raw.githubusercontent.com/Jackjackca/mini/master/alpha-general.json`
- Color Airports: `https://raw.githubusercontent.com/Jackjackca/mini/master/color-airports.json`
- Color Subscription Types: `https://raw.githubusercontent.com/Jackjackca/mini/master/color-types.json`
- Color General Icons: `https://raw.githubusercontent.com/Jackjackca/mini/master/color-general.json`
