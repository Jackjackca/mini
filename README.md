本项目基于 Orz-3 的原创 [mini](https://github.com/Orz-3/mini) 图标项目。

# Egern 图标集

在 Egern 的图标集页面添加远程订阅并粘贴以下任一地址；图标本身也适用于 Quantumult X 1.07 及以上版本、Loon 2.1.10(278) 及以上版本和 Pharos Pro 1.3.3 及以上版本：

- Alpha 通用图标：`https://raw.githubusercontent.com/Jackjackca/mini/master/alpha-general.json` — 315 个图标
- Color 通用图标：`https://raw.githubusercontent.com/Jackjackca/mini/master/color-general.json` — 236 个图标
- Alpha 机场图标：`https://raw.githubusercontent.com/Jackjackca/mini/master/alpha-airports.json` — 87 个图标
- Color 机场图标：`https://raw.githubusercontent.com/Jackjackca/mini/master/color-airports.json` — 87 个图标
- Alpha 订阅类型：`https://raw.githubusercontent.com/Jackjackca/mini/master/alpha-types.json` — 10 个图标
- Color 订阅类型：`https://raw.githubusercontent.com/Jackjackca/mini/master/color-types.json` — 10 个图标

## 各图标集的区别

Alpha 为透明/白色单色图标，适合深色背景，浅色主题下部分图标可能看起来像空白；Color 为彩色图标。通用图标用于流媒体、应用、地区等常用场景，机场图标对应具体机场或服务商，订阅类型对应 SS、SSR、Trojan 等订阅或策略类型。
